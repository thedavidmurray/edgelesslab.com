We Reverse-Engineered Our Own Shop

The insight: Passing unit tests don't guarantee real-world correctness. Our shop's analytics were broken in a way that only appeared under actual buyer traffic—not in isolated tests.

The Problem: Invisible Analytics Blind Spot

Unit tests passed, but live buyer traffic revealed a critical flaw: our shop_real_paths goal was failing because PostHog was only seeing 1 distinct pathname instead of the required ≥2. This meant:

  • Product page routes (/d//) weren't being tracked as separate pageviews
  • Analytics were collapsing all product views into a single entry
  • We couldn't measure actual product interest or conversion funnels

Evidence: Live judge shop_real_paths check showed only 1 distinct pathname in PostHog $pageview despite multiple product visits.

The Fix: Canonical Path Tracking

We rebuilt the routing and analytics layer to ensure real pathnames reach analytics:

  • Product dialogs now use canonical /d// URLs
  • Close/Escape and Back/Forward navigation keep the URL and selected design in sync
  • Legacy ?d= links are canonicalized and preserve campaign query parameters
  • The manual PostHog tracker observes pushState/replaceState/popstate/hashchange events
  • It deduplicates identical URLs and uses actual $pathname, $host, and $current_url (no hash appended or hardcoded host)

Evidence: Isolated routing/pageview implementation passes 9 Node tests, builds 92 edition pages, and passes Puppeteer browser checks for open/close/Back/Forward/Escape/reload/legacy queries/UTM and exact pageview sequence.

Results: From Broken to Working

After the fix:

  • Live Stripe checkout starts successfully (HTTP 200, backend amount 3400 cents)
  • Real buyer probe + REA HAR analysis confirms production selection stays at / before proceeding
  • Live judge pre-deployment: 11/12, exit 1 (only shop_real_paths fails with 1 distinct pathname)
  • Note: The seven-day query window means this improves as new events ingest—no artificial waiting required

Key insight: Tests passed but the live check caught a bug they couldn't see—analytics captured on a stub client vs. real browser behavior.
