20:T1130,<h1>MCP, A2A, AG-UI: Google's Agent Stack and What Actually Matters</h1>
<p>Six protocols. Twelve months. One acronym soup.</p>
<p>MCP, A2A, AG-UI, A2UI, AP2, X402. The agent protocol space is exploding, and most teams are over-focused on model selection while under-specifying the operating surface around the model.</p>
<p>Here's the practical map. Three protocols matter. Three are niche. The rest is noise.</p>
<p>---</p>
<h2 id="the-three-core-protocols">The Three Core Protocols</h2>
<p>Every agent product must answer three questions:</p>
<ol><li><strong>What can the agent use?</strong> → MCP (tools/data)</li><li><strong>Who else can the agent work with?</strong> → A2A (agent coordination)</li><li><strong>How does the human stay in control?</strong> → AG-UI (human control layer)</li></ol>
<h3>MCP: The Security Boundary, Not a Feature Toggle</h3>
<p>MCP standardizes how agents discover and invoke tools. 14,000+ servers now. Claude, Codex, and Google all support it.</p>
<p>But MCP is not safe by default. It was designed for high-trust environments. Tool access enables arbitrary code execution. Invariant Labs documented tool-poisoning attacks that smuggle malicious instructions through tool descriptions.</p>
<p><strong>MCP needs scopes, approval flows, audit trails, and per-context tool visibility.</strong> Treat it as a security boundary, not a feature toggle.</p>
<h3>A2A: The Agent Card</h3>
<p>A2A is cross-organization agent delegation. The key primitive is the "agent card" — a published contract describing what the agent does, what skills it exposes, and how to reach it.</p>
<p>Launch partners: Atlassian, Box, MongoDB, PayPal, Workday. 50+ companies.</p>
<p>But A2A adds coordination cost: latency, failure, permission, and observability problems. Only adopt it when the workflow genuinely requires delegated expertise outside the primary agent.</p>
<h3>AG-UI: The Trust Layer</h3>
<p>AG-UI is not about UI rendering. It's about human control over long-running, non-deterministic agents.</p>
<p>Traditional web apps can't handle streaming, mid-task discovery, or interruption. AG-UI specs cover: streaming, shared state, front-end tool calls, backend rendering, custom events, steering, and sub-agent composition.</p>
<p><strong>"An agent that can't show its work becomes supervision debt for humans."</strong></p>
<p>---</p>
<h2 id="the-three-niche-protocols">The Three Niche Protocols</h2>
<h3>A2UI: Structured UI Rendering</h3>
<p>Sends declarative UI from an approved component catalog instead of arbitrary HTML/JS. Useful for safe agent-generated interfaces. Narrower than AG-UI.</p>
<h3>AP2: Agent Payments</h3>
<p>Cryptographically signed "mandate" proving user authorization. 60+ collaborators including Amex, Coinbase, Mastercard, PayPal. The question: how does the ecosystem know the agent was authorized to buy?</p>
<h3>X402: HTTP-Native Payments</h3>
<p>Coinbase's protocol for agent-to-agent resource payments. Cloudflare adopted it. Buy an API call, a dataset, or a benchmark run without an account or subscription.</p>
<p>---</p>
<h2 id="the-strategic-question">The Strategic Question</h2>
<p>Does Google I/O 2026 stitch these into a single buildable operating model, or just add more standards to the pile?</p>
<p>The first half of 2026 was a golden time for building. The protocols are stabilizing. The question for the second half is whether the stack feels like one operating system or six competing standards.</p>
<p>---</p>
<h2 id="what-to-build-now">What to Build Now</h2>
<ol><li><strong>Audit your MCP servers</strong>: scopes, approvals, audit trails. Read the Invariant Labs tool-poisoning research.</li><li><strong>Design AG-UI control points up front</strong>: approval, edit, interrupt, cancel, progress visibility. Don't bolt them on reactively.</li><li><strong>Evaluate A2A only for genuine delegation</strong>: cross-org workflows that need expertise you don't have.</li><li><strong>Watch payments carefully</strong>: AP2 vs. X402 vs. Stripe. The UX details — fees, returns, re-authorization — matter more than the protocol.</li></ol>
<p>The model is the engine. The operating surface is the car. Most teams are tuning the engine while driving without brakes.</p>
