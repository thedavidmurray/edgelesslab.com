20:Ta0f,<h1>The Creative Demos Collection</h1>
<p>A living archive of 37 interactive generative art experiments. Each demo is a standalone HTML file — no build step, no dependencies beyond a CDN link to p5.js or raw Canvas 2D.</p>
<h2 id="the-philosophy">The Philosophy</h2>
<p>These demos are built on a simple principle: the artifact should be inspectable. Open the file, read the code, change a number, reload. The creative coding pipeline is: idea → code → render → publish.</p>
<h2 id="featured-demos">Featured Demos</h2>
<ul><li><a href="/creative-demos/scroll-chromatic-excavation/">Scroll-Chromatic Excavation</a> — Scroll-driven text excavation with agent swarms and a full control panel</li><li><a href="/creative-demos/scroll-isometric-dissolution/">Scroll-Isometric Dissolution</a> — Isometric typography dissolves into particles under scroll velocity</li><li><a href="/creative-demos/percussive-archaeology/">Percussive Archaeology</a> — Rhythm-driven excavation of buried text</li><li><a href="/creative-demos/cursor-swarm-brush/">Cursor Swarm Brush</a> — 64 particles track your cursor through a recursive geometric subdivision</li><li><a href="/creative-demos/kinetic-type-physics/">Kinetic Type Physics</a> — Physics-driven typography with mass, velocity, and collision</li><li><a href="/creative-demos/monolith-drummer/">Monolith Drummer</a> — 3D monolith that responds to rhythm with WebGL</li><li><a href="/creative-demos/liquid-decryption/">Liquid Decryption</a> — Text emerges from liquid simulation</li><li><a href="/creative-demos/tartan-weave-synth/">Tartan Weave Synth</a> — Interactive generative tartan with 6 weave structures and historical dye colors</li><li><a href="/creative-demos/serial-permutation-canvas/">Serial Permutation Canvas</a> — Visualizing total serialism as particle geometry</li></ul>
<h2 id="the-full-collection">The Full Collection</h2>
<p>Browse the complete collection in <a href="/field-notes">Field Notes</a>.</p>
<h2 id="technical-notes">Technical Notes</h2>
<p>Most demos are built with p5.js 1.9.0. A few use raw Canvas 2D or WebGL. All are self-contained in a single HTML file. The only external dependency is the p5.js CDN link.</p>
<p>The demos are served from <code>/creative-demos/</code> as static files. No server-side rendering, no build step, no framework. Just HTML, CSS, and JavaScript.</p>
<h2 id="remixing">Remixing</h2>
<p>Every demo is readable. Open the HTML file, scroll to the script tag, and modify the constants. The code is not minified or bundled.
