Root cause

The most important result isn't a single bug — it's the reason bugs can ship. Ox flagged an undefined identifier; verifying it against the repo surfaced why the type system never caught it.

P0 · root cause Type checking is switched off at build

next.config.ts sets typescript: { ignoreBuildErrors: true }, and the build script runs no separate tsc gate. TypeScript errors do not fail next build. That is exactly what lets a real ReferenceError — an undefined products in the lazy-loaded home-client.tsx — exist undetected, and it means any future type error can reach production silently. Fix this first; it re-arms the whole type system as a safety net.

Hot spot

One file concentrated a third of all confirmed issues.

workers/ingest/worker.js — 8 confirmed

The PostHog ingest Worker carries a full cluster: unhandled JSON/fetch rejections (bare 500s with no CORS), client-injectable PostHog reserved properties, a wildcard "*" origin that silently never matches, a blocking upstream round-trip on every beacon, and a crypto.randomUUID() fallback that mints a new PostHog person per event — inflating billable MTUs and destroying funnels. One file, eight fixes, real security + billing impact.
