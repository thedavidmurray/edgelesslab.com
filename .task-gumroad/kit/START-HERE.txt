Usage notes
These are reference materials originally assembled in March-April 2026, not a promise of current compatibility. Tool APIs and commands change: check current vendor documentation before installing hooks or running examples. Review scripts, configure your own paths and credentials, and test in a disposable project. No scripts are run automatically. Dependencies and paid API usage are not included.

Validation: original archives downloaded and CRC-tested; bundled Python source syntax checked. Examples have not all been integration-tested against current services. Removed node_modules, generated builds, bytecode, and sales-listing drafts. Original licenses retained per item.
