# Pre-Build Checklist

Complete before starting content creation.

- [ ] Product brief filled out completely
- [ ] Validation score >= 36/60
- [ ] Source material identified and accessible
- [ ] Tier and price determined
- [ ] Directory structure created:
  ```
  product-name/
    content/
    listings/
    README.md
    CHANGELOG.md
  ```
- [ ] Competitor check: reviewed 2-3 similar products
- [ ] Quick start sketched: can describe the first 5 minutes of use
