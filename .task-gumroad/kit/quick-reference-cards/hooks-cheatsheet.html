Hook Event Types
Event Fires When Use Case Blocks?
PreToolUse Before any tool executes Validate input, block dangerous paths, rate limit, log intent YES — can abort
PostToolUse After a tool returns Log results, trigger side-effects, inject context into output NO
Notification Claude sends user a notification Forward to Telegram/Slack, filter noise, augment with metadata NO
Stop Claude finishes a turn / task Run tests, verify completion criteria, send summary email, update backlog NO
SubagentStop A subagent finishes Collect subagent results, trigger next stage in pipeline NO
Hook Response Format
Allow (continue execution)
#!/usr/bin/env python3 import json, sys data = json.load(sys.stdin) # ... your logic ... print(json.dumps({ "action": "allow" }))
Block (abort + message to Claude)
print(json.dumps({ "action": "block", "reason": "Cannot write to /deprecated/" })) # Output to stdout = injects into # Claude's context as tool result # Exit code 0 = allow, non-0 = block
5 Most Useful Hook Configs
1. Damage Control — Block Deprecated Paths
Blocks any write to deprecated directories. Fires on PreToolUse for Write/Edit tools.
{"hooks": {"PreToolUse": [{ "matcher": "Write|Edit", "hooks": [{"type": "command", "command": "python3 .claude/hooks/damage-control.py" }] }]}}
2. Completion Verifier — Run Tests on Stop
Runs the verification script whenever Claude declares a task complete.
{"hooks": {"Stop": [{ "matcher": ".*", "hooks": [{"type": "command", "command": "python3 .claude/hooks/verify-completion.py" }] }]}}
3. Telegram Notifier — Forward Notifications
Sends Claude's notifications to your Telegram bot. Never miss a long task completing.
{"hooks": {"Notification": [{ "matcher": ".*", "hooks": [{"type": "command", "command": "python3 ~/.claude/skills/telegram-message/scripts/send_telegram.py" }] }]}}
4. Session Logger — Write to Vault
Logs a session summary to Obsidian vault after each Claude turn completes.
{"hooks": {"Stop": [{ "matcher": ".*", "hooks": [{"type": "command", "command": "python3 .claude/hooks/session-logger.py" }] }]}}
5. Bash Guard — Block Dangerous Commands
PreToolUse on Bash. Scans the command string before execution. Blocks rm -rf, force pushes, etc.
{"hooks": {"PreToolUse": [{ "matcher": "Bash", "hooks": [{"type": "command", "command": "python3 .claude/hooks/bash-guard.py" }] }]}}
Config location:  Project-level: .claude/settings.json  |  User-level: ~/.claude/settings.json  |  Hook scripts receive the full tool call as JSON on stdin.  |  Timeout default: 10s.
