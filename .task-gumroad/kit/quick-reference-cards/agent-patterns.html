Builder-Validator LOW

pass / fail
One agent builds, a separate agent critiques. Builder never self-validates. Validator returns structured pass/fail with reasons.
Use when: Output correctness is critical. Code review, schema validation, content moderation, test generation.
Trigger: "First build X, then a second agent will validate it against these criteria: [list]"

Split work into independent parallel tasks. Workers run concurrently. Reducer merges results into a single coherent output.
Use when: Work is parallelizable — multi-source research, batch processing, multi-file analysis.
Trigger: "Split this into N independent subtasks. Run each independently, then merge the results."

Load
Linear stages where each step receives the prior step's output. Each stage has a single responsibility. Easy to debug — isolate which stage failed.
Use when: Sequential processing with defined stages. ETL, content enrichment, multi-step generation.
Trigger: "Process this in stages: [stage 1] → [stage 2] → [stage 3]. Return output of each stage."
Supervisor MED
Supervisor
⇄
Specialist A
Specialist B
Orchestrator delegates to domain specialists. Supervisor decides routing, aggregates final answer. Specialists have narrow scope with no cross-talk.
Use when: Tasks require different domain expertise. Mixed code+research+writing workflows.
Trigger: "You are the supervisor. Route each subtask to the appropriate specialist: [list specialists + their domains]"

Answer
Same task sent to N independent agents. Each returns an answer + confidence. Judge picks the majority/highest-confidence answer, or synthesizes when divergent. 3× cost but dramatically higher reliability on high-stakes decisions. Use majority vote (N=3) or weighted confidence (N=5).
Use when: Cost of wrong answer exceeds cost of N agents. Critical classification, security decisions, financial calculations, irreversible actions.
Trigger: "Three independent agents will answer this question separately. Do not share reasoning until all three have responded. Then a judge will synthesize."
