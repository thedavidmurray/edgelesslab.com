Systematic Debugging Flow
01
Read the error before anything else
Here is the exact error message: [paste error] Here is the file and line it points to: [paste code] Read both carefully before suggesting anything.
Force Claude to anchor on the actual error, not a guess at what the error might be.
02
List hypotheses before changing anything
List exactly 3 hypotheses for what could cause this error. For each hypothesis: state it, state what evidence supports it, and state what test would confirm or rule it out. Do NOT write any code yet.
Prevents the common failure mode of jumping to the first plausible fix.
03
Isolate the change that broke it
What changed between when this worked and when it broke? Check: git diff, recent file modifications, env variable changes, dependency updates, config changes. List everything that changed.
The bug is almost always in the diff, not the code that was already working.
04
Read surrounding code before proposing a fix
Before proposing a fix: read the 20 lines before and after the error location. Read the function signature. Read any types/interfaces this function touches. Now propose a fix.
Most wrong fixes come from fixing the symptom without reading the context.
05
Verify the fix does not break neighboring behavior
Before applying this fix: list every other function or test that calls the same code path. State whether the fix could break any of them and why.
One bug fixed, three regressions created is the classic antipattern.
Toolkit Prompts and Anti-Patterns
High-Signal Debug Prompts
"Explain what this code actually does, not what it's supposed to do."
"What are all the ways this could return the wrong value?"
"Trace the data from input to output, showing its value at each step."
"What assumption is this code making that could be wrong?"
"Reproduce the simplest possible version of this bug in isolation."
Anti-Patterns to Avoid
"Fix this." — No context, random fix likely.
"Why doesn't this work?" — Claude will guess without the error.
Pasting 500+ lines without identifying the failure site.
Accepting the first fix without checking for regressions.
When Stuck
"What would you need to see to be more confident in your diagnosis?"
"Assume your first hypothesis is wrong. What else could it be?"
