Context Window Management Strategies
File Filtering
  • Read only the files that are directly relevant to the current task
  • Never load full files when you need one function — specify line ranges
  • Use Grep to locate relevant code before reading the file
  • Exclude test fixtures, generated files, node_modules from context
  • Reference file paths, not contents, for files Claude does not need to edit
Conversation Hygiene
  • Use /compact when the conversation exceeds ~30k tokens
  • Start new conversations for unrelated tasks — do not append forever
  • Summarize completed work into a single message instead of keeping the full thread
  • Remove boilerplate from system prompts — every token costs
  • Use short keys in structured output (not verbose JSON field names)
Prompt Efficiency
  • Prefer bullets over prose in system prompts
  • Use references ("see CLAUDE.md") not inline repetition
  • Avoid "please", "thank you", preambles — they cost tokens and add nothing
  • Batch related requests into one message instead of many round-trips
  • Use structured output — smaller than prose by 30-60%
/compact
Runs when conversation context is large. Creates a compressed summary of the conversation history, replacing the full thread. Use it before starting a new phase of work on a long task. Triggered with /compact in Claude Code. Also happens automatically at ~100k tokens. You can write a custom summary: /compact Summarize progress on the auth refactor, decisions made, and what remains.
