Core Prompt Patterns

CARD 1 / 6
1. Chain of Thought

Force step-by-step reasoning before the answer. Reduces hallucinations on math, logic, multi-step tasks.

Think step by step before answering. Show your reasoning, then give your final answer.
math debugging planning adds tokens
2. Few-Shot

Show 2-3 examples before the real task. Pattern locks in format, style, and edge-case handling.

Input: "hello world" Output: HELLO_WORLD Input: "foo bar baz" Output: FOO_BAR_BAZ Input: "my input here" Output:
formatting classification costly if many
3. Role Assignment

Set a specific expert persona. Be precise — "senior Go engineer" outperforms "expert programmer".

You are a senior Go engineer who specializes in high-throughput gRPC services and prefers table-driven tests.
code review architecture domain tasks
4. Constraint Setting

Define hard boundaries first. What to never do matters as much as what to do.

Rules: - NEVER use external dependencies - NEVER modify files outside src/ - ALWAYS add error handling - ALWAYS write a test first Violating any rule is a hard failure.
CLAUDE.md agents safety
5. Output Formatting

Specify exact output structure. Parseable output means no post-processing regex hacks.

Return ONLY valid JSON. No markdown fences. No explanation. Schema: { "status": "ok" | "error", "result": string, "confidence": 0.0–1.0 }
pipelines APIs automation
6. Meta-Prompting

Ask the model to plan before executing. Surfaces hidden assumptions and forces explicit strategy.

Before writing any code: 1. List what you know about this problem 2. List what you're unsure about 3. State your approach in one sentence Then implement.
