## Full Description

---

Most developers treat prompting like it's guesswork. They copy examples from Reddit, tweak wording until something works, and never understand why. Then the model updates and everything breaks again.

It doesn't have to be that way. Prompting has structure. It has patterns that fail and patterns that reliably succeed. This guide documents all of them.

**What's inside:**

**Part I — Foundations: The Mental Models**
- Ch 01: The Mental Model Shift — why LLMs aren't search engines and why that changes everything
- Ch 02: How LLMs Actually Process Your Input — token budgets, attention, and what the model "sees"
- Ch 03: The Core Four Framework — the four dimensions every good prompt must address

**Part II — The Technique Hierarchy: What Actually Works**
- Ch 04: Clarity and Directness — the single highest-impact improvement most people skip
- Ch 05: Few-Shot Learning and Example Design — how to write examples that generalize, not memorize
- Ch 06: Chain-of-Thought and Extended Thinking — when to use it, when it hurts you
- Ch 07: XML Structure and Semantic Markup — why structure outperforms prose for complex tasks
- Ch 08: Role Assignment and Persona Engineering — what actually works (and what's cargo cult)
- Ch 09: Prefilling and Output Steering — controlling format from the first token
- Ch 10: Prompt Chaining and Decomposition — breaking hard problems into steps that succeed
- Ch 11: Long Context Optimization — placing information where the model will actually use it

**Part III — The System Layer: Your Unique Differentiator**
- Ch 12: System Prompt Architecture — designing instructions that hold up under pressure
- Ch 13: The 8 Template Schemas — a decision tree for picking the right structure every time
- Ch 14: CLAUDE.md Engineering — how to encode your standards so you never re-explain them
- Ch 15: Progressive Disclosure — the three-layer system for context-efficient prompting
- Ch 16: Quality Assurance Patterns — building verification into your prompts, not after them

**Part IV — The Psychology of Prompting**
- Ch 17: The 7 Persuasion Principles for AI — what actually influences model behavior and why
- Ch 18: Combining Principles — sequencing techniques for compound effects
- Ch 19: Anti-Patterns and Sycophancy Traps — how to stop the model from just agreeing with you

**Part V — Agentic Patterns: Multi-Agent Systems**
- Ch 20: Multi-Agent Orchestration — coordinator/worker patterns that scale
- Ch 21: Subagent Prompt Design — writing prompts for agents that need to stay in their lane
- Ch 22: Skill Architecture — modular, composable instructions for complex pipelines
- Ch 23: Closed-Loop Self-Correction — prompts that check their own work
- Ch 24: Consensus and Voting Patterns — using disagreement as a quality signal

**Part VI — The 8 Development Patterns**
- Ch 25: Production-tested patterns including Iron Law, Reconnaissance, Progressive Fallback, and five others with full examples

**Part VII — Anti-Patterns**
- Ch 26: The Deadly Seven Anti-Patterns — the most common mistakes with specific fixes for each

**Part VIII — Applied Domains**
- Ch 27: Software Engineering Prompts — code review, debugging, architecture, testing
- Ch 28: Content and Writing — briefs, editing, voice consistency, structured output
- Ch 29: Image Generation — prompt anatomy for diffusion models
- Ch 30: Business and Strategy — analysis frameworks, decision support, research synthesis

**Appendix A: Quick Reference Cards** — cheat sheets for the Core Four, Template Selection, and the Deadly Seven
