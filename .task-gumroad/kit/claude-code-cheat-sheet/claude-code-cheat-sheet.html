⌨ CLI Commands
claude — start interactive session (REPL)
claude "prompt" — one-shot, print response, exit
claude -c / --continue — resume last conversation
claude -r / --resume — pick a past conversation to resume
claude -p "prompt" — pipe/headless mode (no UI, stdout only)
claude --model — specify model (e.g. claude-opus-4-5)
claude --verbose — show all tool calls and reasoning
claude config — open settings (model, API key, etc.)
Key Flags
--allowedTools — whitelist specific tools (space-separated)
--disallowedTools — blacklist specific tools
--max-turns — cap agentic loop iterations
--dangerously-skip-permissions
Skip all permission prompts. CI/scripts only — never interactive.
Headless Pipeline Pattern
echo "Fix all lint errors" | claude -p --allowedTools Edit,Bash \
  --dangerously-skip-permissions

Skill / Custom Slash Commands
Any skill.md at .claude/skills/name/ is invoked
as /name inside a session. Skills listed in
CLAUDE.md auto-load based on trigger patterns.

# filenameAdd a file to the current context window

🪝 Hooks
Event Types
PreToolUse PostToolUse Notification Stop SubagentStop
Config Location
.claude/settings.json or ~/.claude/settings.json 
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Write",
      "hooks": [{
        "type": "command",
        "command": "./lint.sh"
      }]
    }]
  }
}
Hook Return Values
allowLet tool proceed normally
blockHalt tool, return reason to Claude
modifyAlter tool input before execution
{"decision": "block", "reason": "No writes to /etc"}
🤖 Subagents & Skills
Subagent Types
Task foreground
Blocks parent until complete. Use for sequential work.
Background async
Non-blocking. Parent continues; get result via callback.
Worktree isolated
Separate git worktree. Safe for parallel branches.
Key Params
subagent_typetask / background
promptTask instructions for the subagent
run_in_backgroundtrue → async execution
isolation"worktree" → git isolated copy
Skills
Location .claude/skills/ or ~/.claude/skills/
Format skill-name/skill.md with YAML frontmatter
Invoke /skill-name or auto-matched by triggers 
## skill.md frontmatter
---
name: my-skill
triggers:
  - "deploy"
  - "release"
---

Common Servers
filesystemRead/write file system access
fetchFetch URLs, web content
githubGitHub API (PRs, issues, repos)
playwrightBrowser automation
chromaVector DB semantic search
Tips
Disable unused servers to reclaim context tokens.
Use env key for secrets (e.g. API keys).
Project .mcp.json overrides global for same name.

🔒 Permission Modes
Default (safe)
Prompts before every tool use. Recommended for interactive work.
--allowedTools whitelist
Auto-approve listed tools, prompt for others. Best for scripts.
--allowedTools Bash,Edit,Read
--dangerously-skip-permissions
All tools auto-approved. CI / automation only. Never use interactively.
