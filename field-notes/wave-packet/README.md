# Field Notes / Where the packet ends

Self-contained interactive study: open `index.html` in a browser. `field-note.png` is the exported still. `verify.py` checks the working interaction and exports the still via Chrome/Playwright. Source: [Sabine Hossenfelder, *Why Quantum Physics Messes With Reality*](https://www.youtube.com/watch?v=ecTutLU2n48); [vault note](../../../claude-vault/03-Knowledge/YouTube/SabineHossenfelder/Why%20Quantum%20Physics%20Messes%20With%20Reality.md).

## Draft caption (two sentences)

Free evolution predicts where a detection is likely, and repeated clicks trace that distribution. It does not select the click in a single run; Hossenfelder's “half-information” ceiling is a separate claim about access to a complex-valued state through real-valued measurements, not a 50% chance of a click.

## Parameters / method

A 1D minimum-uncertainty Gaussian free particle starts with position-density standard deviation σ₀ = 0.62 length units. At time t, σₓ(t) = σ₀√[1 + (t/τ)²], with τ = 2mσ₀²/ℏ. Curves are shown at t/τ = 0, 1, 2.5, giving widths 0.62, 0.88 and 1.67. The plotted height is the normalized Gaussian probability density, not the complex wave amplitude. One detector point and 240 independent points are generated by Box-Muller draws from the Gaussian |ψ(x,2.5τ)|²; the display bins repeat points into a dot histogram. Fixed-seed PRNG makes each displayed run reproducible, while the button varies its seed. The axis is dimensionless except for the chosen length unit. No collapse dynamics or detector microphysics are modeled.

## Limits / next pass

This plate illustrates the measurement-outcome gap, not a demonstration of decoherence, and neither the three curves nor the dot stack explain phase or interference. The “half-information” framing is attributed to the source and should not be advertised as a general theorem: informationally complete measurements on identically prepared ensembles can recover a quantum state up to global phase under standard assumptions. A future plate could add a phase-sensitive preparation/interference panel, detector efficiency and finite resolution, explicit units, and a time animation; keep the single-click versus many-runs distinction. At high zoom, adjust mono label spacing near the right end of the x-axis if localized fonts cause overlap.
