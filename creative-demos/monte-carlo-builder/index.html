Inside the experiment

This tool runs Monte Carlo stress tests on trading strategies. Input can be:

  • CSV of per-trade returns (e.g. 0.02, -0.01, 0.03)
  • Equity curve (cumulative P&L) - converted to returns
  • Parametric (Normal, Student-t, Bootstrap) - generates synthetic returns

Methods run:

  • Trade-order shuffle (permutation test)
  • Block bootstrap (preserves autocorrelation)
  • Resampling with replacement
  • Parametric simulation (from fitted distribution)
  • Random-entry permutation test vs strategy returns

Outputs include fan chart of equity paths, terminal wealth histogram, max drawdown distribution, probability of ruin, Sharpe distribution with confidence intervals, comparison vs buy-and-hold, and a verdict box that reports number of variants tried and refuses to say "edge" unless the strategy beats the null at a stated threshold.

This is a simulation for paper trading context only. No forecasting. No trading advice.
